# Smart Bank Management System

A menu-driven banking management system built in C, developed as a group project.

## Features

The system is divided into four modules:

- **Customer Management** – add, view, search, update, and delete customer records
- **Account Management** – create and manage Savings/Current accounts linked to customers
- **Transaction System** – deposit, withdraw, and view transaction history
- **Loan Management** – apply for, approve, and repay loans
